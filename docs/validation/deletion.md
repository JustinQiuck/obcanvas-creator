# 0.4.2：卡片删除验收

日期：2026-09-11。宿主：Obsidian 1.13.7。

## 问题与改动

0.4.1 仅实现连线与媒体关联移除，没有卡片删除入口。新增详情顶部按钮、卡片聚焦时的 Delete／Backspace 操作和带标题的确认弹窗。确认前先保存当前编辑；笔记变更、身份重复或回收站失败会保留内容并显示原因。

卡片笔记通过已安装宿主类型定义中的 `Vault.trash(file, false)` 移入库内回收站。其他笔记、图片和视频不删除；跨场次引用、镜头顺序和布局保留，原笔记恢复后可继续解析。纯素材节点没有独立笔记，移除它只解除当前场次的关联，已有采用记录会阻止移除。

## 验证结果

- 类型检查、构建及全部 42 项逻辑测试通过，新增 3 项删除回归测试覆盖共享媒体、回收站失败、并发修改、重复 ID、恢复与部分关联写入失败。
- `npm run test:deletion`：隔离资料库 5 项实机检查通过。覆盖输入退格、保存最新标题后确认、取消、聚焦卡片与原选中卡片不同、实际库内回收站内容比对、已采用媒体的错误提示、素材移除与源文件字节保留。
- 完整重启后 `npm run test:deletion:reopen`：1 项检查通过，已删除卡片未重新出现，原笔记和媒体仍在。
- 验证中发现键盘焦点可能与选中卡片不同，已修正删除目标为实际聚焦卡片并复验。一次测试实例退出超过启动脚本等待上限，后续重新启动及最终退出均成功，不涉及正式实例。
- 正式资料库备份至 `.obsidian/obcanvas-backups/20260911-122029-0.4.1/` 后，仅替换四个插件安装文件；实际界面显示 0.4.2 及「删除卡片」按钮。
- 启用后 13 份项目笔记、任务／布局 JSON 与配置逐字校验保持不变；未删除正式卡片，未发起模型调用。
- `dist/obcanvas-creator-0.4.2.zip` CRC 与安装文件字节一致。

测试材料与结果只存于忽略的 `.local/`，未提交私人项目内容。当前是单卡删除，不包含批量删除、场次删除或插件内回收站界面；恢复使用资料库 `.trash`。多笔记素材关联移除可重试，不承诺跨文件事务。
