# 多模型配置与选择 · 0.8.0

日期：2026-09-12。

## 使用方式

Obsidian 设置 → 影视画布 → 编辑模型配置 → “＋ 新增模型配置”，填写配置名称、服务地址、模型名称与独立密钥，保存。现有配置可从同一下拉框选中后修改。

项目库和项目工作台顶部的“文字模型”选择当前资料库用于后续任务的配置。选择在多个画布视图间共享，重启后保留；任务执行期间前端禁止切换。资产整理和分镜任务在启动时取得地址、模型与密钥快照，后续配置修改不会改变已启动任务。

本阶段只支持通用 Chat Completions 文字接口。模型配置与 Skill 独立，图片、视频仍由外部工作流生成。测试连接只有主动点击才会发送中性短消息。

## 存储兼容

- 旧 `ai` 设置自动读作“原有模型配置”，沿用原 Obsidian 密钥名称。
- 多组非密钥设置与当前选择保存到插件 `data.json` 的 `models` 字段；未知字段及草稿保留。
- 每个新配置以稳定编号对应独立的 Obsidian 密钥项。无密钥存储的宿主使用按配置隔离的会话密钥。
- 未编辑密钥栏时保留该配置密钥；配置保存失败回退密钥和内存配置；草稿保存与配置写入串行化。
