# 0.5.0：可选资产 Skill 验收

日期：2026-09-11。宿主：Obsidian 1.13.7。

## 交付范围

资产整理阶段提供通用剧情与音乐 MV 两项内置规则、项目默认和剧本单独选择。中文管理窗口支持查看、复制为自定义、编辑、Markdown 导入和导出。一次提取加载所选 Skill 及统一资产输出协议。每次任务保存实际使用的规则与版本，换规则不会自动运行或改写已确认内容。

音乐 MV 规则处理演出、空间与意象资产，明确不把歌词比喻直接当成画面实物、不猜 BPM 或时间点。分镜节奏与提示词设计属于后续阶段，本版本没有伪装成可用的分镜选项。

## 已验证

- 类型检查、构建、47 项逻辑测试及差异格式检查通过。
- `mv-asset-extractor` 通过 skill-creator 的 `quick_validate.py`，不代表真实模型判断质量已经验证。
- `npm run test:assets-ai`：原资产准备 10 项隔离宿主回归通过。
- `npm run test:skills`：5 项实机检查通过，覆盖 MV 规则确实进入请求、自定义复制保存后进入请求、项目默认与剧本覆盖独立、修改规则不改变历史任务也不自动调用、Markdown 导入导出、未保存关闭提示、模型配置与 Skill 配置互不覆盖。
- 完整重启后 `npm run test:skills:reopen`：1 项检查通过；恢复项目默认、剧本选择、自定义规则及历史快照，测试前全部项目笔记逐字保持不变。
- 重启脚本第一次在历史任务尚未异步读完时过早断言；增加等待指定任务载入后通过，存储内容未丢失。
- 逻辑测试补充并发配置写入保护、保存失败、缺失配置／选择、内置规则防覆盖、规则快照隔离、旧任务兼容、阶段错误及长度限制。
- 按既有本地升级授权，备份到 `.obsidian/obcanvas-backups/20260911-200515-0.4.2/` 后替换四个安装文件，正式界面显示 0.5.0、Skill 选择与管理入口。
- 启用后 9 份已有项目笔记／JSON 及插件配置逐字保持不变；未写入测试 Skill，未替用户运行提取。
- `dist/obcanvas-creator-0.5.0.zip` 完整性及文件字节校验通过。

## 限制

请求验证使用隔离本机模拟服务，不验证真实模型的风格遵循或提取质量。自定义 Skill 当前仅支持资产整理阶段的自包含 Markdown 文字，不支持目录包、外部参考文件、脚本、工具调用、分镜设计或节奏分析。导入任意外部 Skill 不保证语义兼容；无效结果依旧通过统一校验显示逐项问题。

配置文件与任务快照位于资料库内，随资料库一起备份。未保存的自定义编辑留在管理窗口，关闭会提示放弃；尚不提供应用崩溃后的自定义编辑草稿恢复或 Skill 删除界面。
