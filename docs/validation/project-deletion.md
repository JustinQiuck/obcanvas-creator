# 项目删除 · 0.7.2

日期：2026-09-12。

进入项目后，顶部“修改项目名称”旁提供“删除项目”。确认框显示项目名称、笔记总量以及剧本、拍摄资产、镜头数量；默认聚焦取消。确认后将所属记录移入资料库 `.trash` 并返回项目库。

图片、视频源文件、AI 任务记录、Skill 配置及布局保留，其他项目不改动。恢复时将本项目笔记从 `.trash` 放回原位置。未命名的旧项目同样支持删除。

删除前重新核对确认快照，执行中复核剩余范围；子项先于场次，项目笔记最后移除。发现内容变化或回收站失败时停止，报告已完成数量，允许取消后重新检查、确认剩余内容。多文件操作不是原子事务。

- 隔离 Obsidian 1.13.7：含一份剧本的项目显示 3 份笔记；取消后项目完整；确认后返回项目库且项目消失。
- 文件校验：仅目标 3 份笔记移除，其余文件哈希一致；回收站中三份笔记与删除前一致。
- 将笔记从回收站放回后，项目及一份剧本重新出现在项目库。
- 备份旧插件后安装到当前资料库；安装证据存于 Git 忽略的 `.local/project-delete-install.json`。本次未删除任何正式项目。
