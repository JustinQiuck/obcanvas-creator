# 新建剧本项目修复 · 0.7.1

日期：2026-09-12。

## 问题与范围

用户反馈无法新建剧本项目。现场看到名称为空，新建按钮被禁用且没有解释；未收到更具体的失败步骤。同时检查发现名称直接拼入文件路径，示例中的斜杠会形成不存在的子目录，长中文名称也可能超过文件名长度限制。

空名称现在允许点击后给出中文提示并聚焦名称输入框；输入时清除提示。新增笔记使用类型与唯一编号作为文件名，完整名称保存在笔记属性中。既有笔记不改名、不迁移。

## 验证

- 类型检查、构建通过；60 项自动测试通过。
- 新增回归覆盖斜杠、反斜杠、文件名特殊字符及 250 字中文名称，检查路径处于项目根目录、文件名长度及重新读取后名称完整。
- 隔离 Obsidian 1.13.7 内点击空名称按钮，显示“请先填写项目名称，再点击新建。”并聚焦输入框。
- 隔离库通过回车创建 `/ MV`；通过按钮创建 `回家 / 夏日音乐 MV`，进入独立项目工作台。
- 完整重启隔离实例后，中文项目名与工作台恢复正常。
- 当前正式资料库已备份旧插件并安装 0.7.1，重新启动后界面显示新版本及填写提示。安装前后 16 个项目文件哈希一致；原有 2 份剧本、7 项拍摄资产保持可见。
