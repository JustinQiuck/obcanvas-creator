## 流程核对

- 正常流程：正式镜头及全片顺序 → 主段 → 参考/时间窗/文案 → 冻结尝试 → 外部执行 → 导入 → 逐镜实际区间。
- 部分失败：段含两镜，一镜可用、一镜补拍；补拍采用只改变目标镜头，原段汇总可完成，旧候选仍可查。
- 计划变化：拆并或改镜头后旧尝试保持原输入，新方案检查唯一覆盖，中断可恢复，不自动替换采用。
- 连续性：A1 → B1 → A2 的剪辑次序与 A2 引用 A1 实际帧分别登记；独立 B 段不被连带置为失效。
- 旧数据与外部输入：无区间、无尝试、外部待挂图、文件缺失和项目恢复都保留已知事实，缺项单独显示。

以上是规范走查，尚无生成段运行时可供验收。未在本次范围内发现新的规划阻塞；具体字段读写、宿主交互、真实 H3 模式和多镜生成效果须按 GS 切片验证。
