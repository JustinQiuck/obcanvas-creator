# 分阶段 Skill 选择

日期：2026-09-11。用户确认按资产整理、分镜设计、提示词整理区分 Skill。现有资产整理阶段已在 0.5.0 实施，通过 [隔离验证](validation/skills.md)。

## 当前切片

- 在剧本卡执行前显示资产 Skill 下拉选择；默认跟随项目设置，也可为当前剧本单独选择。
- 保留通用剧情资产 Skill，增加独立的音乐 MV 资产规则，不规定镜头节奏或凭空补音乐时间点。
- 中文 Skill 管理入口支持查看内置规则、复制为自定义、编辑和导入／导出 Markdown。只加载文字规则，不执行附带脚本或加载外部资源。
- 资料库内独立保存 Skill 配置、项目默认和剧本选择。更新插件不覆盖用户 Skill；并发修改和保存失败显示原因。
- 任务保存实际使用的 Skill ID、名称、版本及规则快照；换 Skill 不自动运行、不覆盖旧任务与已确认资产。
- 宿主统一注入任务范围和输出协议，校验器仍要求可回查原文与有效已有资产。用户编辑规则不需要编写 JSON。

## 验收

验证规则切换确实改变模型请求、项目默认与剧本覆盖可重开恢复、自定义规则修改不改变历史快照、旧任务兼容、格式错误可诊断、保存冲突不覆盖。隔离资料库用模拟接口测试，不调用用户模型或改动正式资产。

## 后续阶段

2026-09-12 已补充 [Drama Skills 接入计划](drama-skills-integration-plan.md)：四项能力分批适配，先验证分镜价值。资产整理继续沿用现有入口；新增阶段分别使用自己的输入输出契约，主方法、作品风格与生成目标分开配置。内置方法按审定片段打包，不把多文件 Skill 原样放进当前单 Markdown 导入口。以下方向保持有效，尚未实现的执行入口不提前展示。

分镜 Skill 决定景别、机位、镜头理由、段落与衔接；MV 分镜需音乐段落／时间标记，未知时先询问，不猜节拍。提示词 Skill 将确定镜头转换为参考关键帧与视频动作描述。0.6.0 已加入固定的剧情分镜试点方法和预览按钮，用于先验证规则价值；分镜阶段的选择、自定义与正式入卡仍属于 DS02，也不把资产 Skill 当作节奏风格控制。
