# ObCanvas Creator

> 已按实操反馈改为自由画布；交互方向见 [改造计划](docs/canvas-reset.md)。

面向 AI 影片制作的全中文工作台：结合现有画布的可视化操作与 Obsidian 的本地项目文件，管理剧本、分镜、参考图、视频候选和关键帧。

**当前版本：0.5.0，已更新到当前 Obsidian 资料库。支持按剧本选择资产整理 Skill、项目默认规则、自定义编辑与 Markdown 导入导出，保留历史规则快照；通用模型、资产绑定和卡片删除功能继续可用。隔离 Obsidian 模拟接口和重启检查通过；真实模型判断质量仍需实测。AI 分镜、节奏设计、资产提示词、视频截图和制作包尚未实现。**

本地开发根目录：`/Users/aliceboy/项目文件/闲来无事/obcanvas-creator`。后续源码、开发记录及从原画布复用的文件统一放在本仓库，复制后以本仓库版本为准。

## 要解决的问题

打开一场戏，就能回答：有哪些计划镜头、已经生成哪些视频、采用了哪个版本、还缺什么，以及哪张截图将用于后续镜头。

操作入口：先放剧本或素材 → 连接用途 → 补充镜头 → 外部生成 → 放回视频并选片。画布不强制按步骤操作；截图续接仍待实现。

## 已确定的方向

- 全中文操作。通过画布整理项目，不要求手写 Markdown 属性、JSON 或英文命令。
- Obsidian 资料库保存正式项目记录；画布显示和编辑同一份数据。
- RunningHub 负责外部生成。工作台接收结果，不管理工作流升级、节点参数、提交或轮询。
- 每个镜头可有多个候选视频，同一视频也可供多个镜头使用。导入视频不等于采用。
- 保存采用区间、截图来源与用途；连续续接和换机位分别处理，不强制每个镜头继承上一镜末帧。
- 复用现有画布中适合的组件，逐步接入 Obsidian。已复制必要的背景／视口组件与主题，见 [复用记录](docs/source-reuse.md)。

## 本地运行

```bash
npm ci
npm run typecheck
npm test
npm run prepare:test-vault
npm run launch:test-vault
```

测试启动脚本当前支持 macOS，使用 `.local/test-vault/` 和独立应用配置。打开后从侧栏“影视画布”进入，创建场次与镜头，保存后点击“打开对应笔记”查看双向更新。用 `npm run stop:test-vault` 停止独立测试实例。

插件安装文件是构建后的 `main.js`、`styles.css`、`manifest.json` 和 `licenses/infinite-canvas-MIT.txt`，最低 Obsidian 版本为 1.13.7。实机验证见 [P0-A](docs/validation/p0-a.md)、[P0-B 画布](docs/validation/p0-b.md) 和 [P0-C 素材](docs/validation/p0-c.md)。

## 自由画布基本操作

1. 从侧栏打开「影视画布」，点击「＋ 剧本」粘贴内容，也可以直接把图片或视频拖入空白画布。无需先创建镜头。
2. 添加人物、场景、镜头或关键帧卡。点击卡片展开详情，拖动卡片调整位置；空白处拖动平移，滚轮缩放，「总览」查看所有卡片。
3. 点击卡片右侧圆点，选择用途，再点击目标卡片。「视频候选」需连接到镜头；「起始帧」必须有实际图片。
4. 点击镜头，在详情中播放候选视频，采用或填写原因后退回。选择属于该镜头，共享视频在别的镜头中的决定不变。
5. 「查看待办」定位未完成镜头；「镜头顺序」调整成片顺序，拖动坐标不改变顺序。

标题和正文可点击「保存到笔记」保存；切换卡片、关闭详情或切换场次时先保存，失败保留输入并显示原因。未保存草稿可以在重开后恢复。当前资料库作为项目边界，场次用于区分不同画布。

文件复制入库会保留原文件。超过 256 MB 的文件先放进资料库，再用「关联库内素材」。移除连线不删除文件，已采用视频需先取消采用才能移除关联。选中卡片后，点击右侧详情顶部「删除卡片」→「移入回收站」，或在卡片上按 Delete／Backspace 后确认。笔记进入资料库的 `.trash`，不删除图片和视频；输入框中的退格仍只编辑文字。共享资产删除后其他卡片的引用暂不可用，将笔记从回收站放回原处可恢复关系与布局。只有素材引用的卡片显示「移除素材卡」，仅移除当前场次的关联。

新版实机验证：`npm run test:free-canvas`；完整重启隔离实例后执行 `npm run test:free-canvas:reopen`，见 [0.3.0 验收记录](docs/validation/r1.md)。P0/P1 旧宿主脚本保留历史界面断言，不作为新版界面验收命令；逻辑测试仍由 `npm test` 执行。

删除验收：`npm run test:deletion`，完整重启后 `npm run test:deletion:reopen`；见 [0.4.2 验收](docs/validation/deletion.md)。

## 0.4.0：从剧本准备资产

1. 打开 Obsidian 设置 → 影视画布，在“AI 助手”填写服务地址（例如 `https://服务域名/v1`）、模型名称和密钥。保存后可主动“测试连接”；此操作发送中性短消息，可能产生服务费用。
2. 打开剧本卡，粘贴剧本，点击“整理拍摄资产”。插件先保存剧本，再发送该剧本和项目已有资产的必要文字摘要；不上传参考图片。
3. 检查人物、场景和道具清单：修改名称，核对原文依据，选择新建、复用或忽略；同类重复项可合并。修改自动保存，失败时请在当前窗口修正或重试。
4. 点击“确认并生成资产卡”，然后点击“绑定参考图 · 资产名”。没有 AI 配置时也可手动添加人物、场景、道具，再在剧本的“关联已有拍摄资产”中选择。
5. 在资产卡导入或关联图片，指定“主参考／空间全景”等用途，检查后点击“确认使用此图”。“查看待办”显示待确认信息、缺图和需复核的资产。

复用资产跨场次保持同一身份；导入图片不会自动确认，图片变化需重新检查。剧本变更后旧提取清单保留供对照，需按当前剧本重新整理。RunningHub 继续负责外部生成。

测试命令：`npm run test:assets-ai`；完整重启隔离实例后 `npm run test:assets-ai:reopen`。测试脚本启动本机模拟接口，不使用真实服务或生产资料库。

## 0.5.0：选择和自定义资产 Skill

在剧本卡“资产整理 Skill”中选择「通用剧情资产」「音乐 MV 资产」或自定义规则。默认跟随项目设置，也可为当前剧本单独指定；一次提取只使用所选的一项规则及宿主输出协议。

点击「管理 Skill」可设置项目默认、查看内置规则、复制为自定义，或导入 Markdown。修改名称和规则后点击「保存并用于此剧本」；导出 Markdown 可保留和复用自己的规则。内置内容只读，复制后可编辑；只导入文字，不执行脚本或加载附带资源。

点击「重新提取拍摄资产」才会发起模型请求。选择或修改 Skill 不自动运行，也不改写旧清单或已确认资产；新清单记录所用名称、版本和规则快照。MV 资产规则侧重演出、空间和视觉意象，不把歌词比喻直接当成确定道具；它不负责音乐节拍或分镜设计。

测试：`npm run test:skills`；完整重启后 `npm run test:skills:reopen`。见 [阶段计划](docs/skill-selection-plan.md) 和 [验收记录](docs/validation/skills.md)。

## 已验证的选片循环

[P1 验收](docs/validation/p1.md) 已通过以下“一场戏、三个镜头”循环：

1. 镜头 A 有两个视频候选，采用其中一个。
2. 镜头 B 没有素材，显示待补。
3. 镜头 C 的候选被退回，显示待重做。
4. 关闭重开后，顺序、素材关联和采用决定仍然正确。

[AI 助手与资产准备](docs/agent-assets-plan.md) 已实现，验证范围见 [0.4.0 验收](docs/validation/a-assets.md)。分镜辅助、制作包与截图依赖仍待实施。
